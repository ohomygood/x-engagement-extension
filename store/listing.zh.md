# Chrome 应用商店文案 — 简体中文

**名称：** X 互动名单助手 — 评论排行与回关检查
**简短描述（≤132 字符）：** 看谁最常评论你的 X 帖子、哪些评论还没回、谁没回关你。数据只存在本地。

## 详细描述
X 互动名单助手把你在 X 上已经看到的内容整理成清单：不需要登录、不做任何自动操作、数据不上传。

**功能**
- **评论排行（近 7 / 30 / 90 天）：** 谁最常回复你的帖子，并附上 TA 最近一条回复的链接。
- **待回复：** 你的帖子下还没有回复的评论。
- **未回关：** 打开你自己的「正在关注」页面，点击「开始记录快照」，扩展会以接近人工的速度慢慢滚动（约每 2 秒一屏，可随时停止），列出没有回关你的人。
- **取关提醒：** 对比两次完整的「关注者」快照，看看谁取关了。
- **CSV 导出与多账号**（Pro）。

**工作方式**
扩展只读取你在自己浏览器中打开的 X 页面（你的帖子、回复、通知、你的关注/粉丝列表），并保存在浏览器本地数据库中，不会上传。数据只会随你浏览而增加：不调用 X API，也不会替你浏览；唯一的例外是你在自己的列表页主动开启、可随时停止的快照滚动。

**绝不会做的事**
不关注、不取关、不点赞、不回复、不私信；不需要密码或 X API 密钥；无追踪、无广告。
